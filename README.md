# My Pilot Life

A dark, English-language installable web app for organizing a flight-simulation career.

## Current starter features
- Dashboard with flight count and total logged time
- Manual flight schedule
- Personal flight logbook
- Local device storage
- Offline app-shell caching after first visit
- Export local data as JSON

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to publish the site.

## Install on iPhone
Open the published GitHub Pages URL in Safari, tap Share, then **Add to Home Screen**.

## Not included yet
This starter does not connect to SimBitWorld A Pilot's Life, provide live flight tracking/maps, or send push notifications. Those require a documented API and additional implementation.
